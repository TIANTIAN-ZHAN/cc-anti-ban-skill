# 隐私与授权边界

## 本地读取

服务启动会继承进程环境，但不自动执行本地检查。用户在页面确认或显式使用 `check --local-consent` 后，检查会枚举完整 `NAME=value` 环境，并有界读取固定用户 settings.json 原文；其中可能含 API key、代理 userinfo、私钥设置或其他敏感值。最多读取 65,537 字节判断是否超过 64 KiB，超限即拒绝；固定 home root 内路径禁止最终符号链接、目录/FIFO 等非普通文件和越界链接。

原文及解析字符串会进入本地内存；结构检查会解码 env 字符串，候选启动还会重读并比较代理/旁路等必要字段。基线在会话内保存配置全文 SHA-256、允许列表环境摘要、来源元数据、CLI/工作目录等执行上下文和必要路由信息；不把原文发送给外部服务、写入日志或导出。原文不挂入返回的基线对象，但没有立即覆写内存的保证；cleanup-only 期间仍可能保留基线，不能声称 15 分钟后所有内存数据销毁。

不主动打开账号/独立凭据文件、Keychain、浏览器 profile/Cookie、订阅、聊天或私钥文件；这不等于配置/环境里绝不出现凭据值。mTLS/provider 的环境值会由枚举/LookupEnv 取得，业务判断只保留存在性；DYLD 按名称识别，不在快照里保留或输出值。代理 userinfo 被本地解析后拒绝使用，不发送也不写入报告。只读检查不执行配置中的 hook/helper/命令；另行批准正常启动 Claude 后，其他环境可能含凭据并正常传给它，它也可能自行联网/执行这些逻辑。

CLI 绝对路径与工作目录只在本地新会话确认卡展示供用户核对，代理/DNS 地址只在对应外联确认清单展示；它们不写入应用日志或报告导出。确认卡中的批准二进制摘要与服务端的环境/settings 绑定摘要用途不同；后两者不导出。

`claude --version` 仅在 macOS 默认拒绝沙箱内执行，只允许读取已解析的 CLI 文件与固定系统运行库/解释器，不放行 CLI 所在目录或用户目录；禁止网络、文件写入和派生进程。最长 3 秒，输出上限 4 KiB，stderr 丢弃；只有匹配固定版本格式的数字进入报告。沙箱不可用或官方 CLI 需要超出允许范围的运行依赖时未知，不无沙箱降级。进程不继承认证或代理环境。假 CLI 的沙箱验收不等于真实官方 CLI 兼容性验收。

## 主动外联

页面预览只生成清单，不联网。目标固定 `https://api.anthropic.com/`，代理仅来自已检查的启动环境；网页不能输入 URL、代理、DNS 地址、路径或命令。清单显示明确的直接接收方、发送的数据、最多次数和 12 秒总超时。批准一个清单只允许一次尝试，失败消耗清单，重试要重新确认；没有重定向、模型或凭据请求。

DNS 的单服务器 A 查询只是参考，不是 macOS split DNS 的复现；其失败不判 Claude 失败。网络连接会向所列 DNS/代理/目标暴露连接来源和必要协议数据，代理/DNS 上游不由本工具控制。清单仅在当前页面内短暂展示这些必要地址，不写进日志或导出报告。

本机得到的目标或代理域名 DNS 回答必须全部是允许的公网 IPv4；混合回答包含回环、私网、链路本地、100.64/10、保留、特殊用途或不支持的地址就整体拒绝，在任何目标/代理 TCP 拨号前停止。唯一例外是用户在清单中明确选择的字面回环代理端点；不能把该例外用于固定目标或解析到回环的代理域名。代理内部的目标 DNS 与转发仍未独立验证。

固定公开 `/etc/ssl/cert.pem` 在探测时只读加载到独立 Go 证书池，强制验证主机名/CA/TLS 版本，不通过关闭证书检查或系统信任服务隐式联网补证书。自定义 provider、mTLS、认证代理、自定义信任等不支持范围停在未知，不回退猜测。

AWS/Bedrock/Mantle/Vertex/Foundry、宿主管理、网关或相关 base URL 字段只作为目标不确定的线索，不把字段存在（包括空值/0）称为已生效。已观察的本地配置存在但未读、无效或读取失败也阻断默认清单。没有发现这类线索的完整本地假设可做明确标注的 shell 参考检查；remote/MDM 和运行中进程的最终配置始终未知，不能因参考分数高而升级为已验证。

## 本机服务

只监听 `127.0.0.1:随机端口`，精确验证 Host（含端口）。API 全部要求 POST、精确 Origin、JSON、随机会话凭据；缺 Origin 也拒绝。一份启动凭据只能换取一次会话，URL 片段不会发到服务器。仅固定静态路径与固定动作，无全局 CORS，无任意读文件/命令/目标接口。响应禁止缓存，严格 CSP 禁止外部脚本/连接和被 iframe 嵌入。

会话及证据仅在内存中。普通活动授权最多 15 分钟，页面可明确结束；先取消在途活动且禁止新阶段，已发请求仍保留证据。残留时仅留原认证状态/清理入口，完成才退出；启动过受控交互后 Ctrl-C 保留给该终端交互，避免迟到信号误关页面服务。关闭/到期会请求停止仅本次拥有的根进程，必要时有界强制停止并等待退出/终端恢复；不注册后台任务。页面刷新后不恢复会话。导出是用户主动动作，实际报告不得进入版本库；`.gitignore` 只是辅助，不替代提交检查。工具受限或页面被拒时不得换协议/代理/工具绕过限制。

## 修复与表述

已实现一次确认后仅为新进程应用本机 HTTP 代理与单次参考复测，不修改系统、父环境或配置文件，因此没有配置文件备份/恢复。计划列出变量副本变更、绑定 CLI/工作目录、启动副作用、参考预算及停止边界。正常 Claude 的联网/写入/hooks 不受参考预算保证；停止根进程不撤销已有副作用或保证全部后代退出。当前暂停范围和任务授权始终优先，不把“实现适配器”当成“操作真实设备”的授权。

不自动换节点、国家/语言、清 Cookie、禁 IPv6、降低安全保护或执行管理员操作。代理标记、DNS 地区或时区差异不直接等于泄露、不可用或会封号。明确区分示例、伪造 fixture、局部真实探测、账户/模型验证，未知不改写成通过。

CLI 绑定以不跟随最终链接、非阻塞打开核验普通文件，限制大小并可取消散列读取；计划与执行前重新核验身份。终端操作不切换前台组，恢复前再次确认仍拥有前台；若前台已转移就报告未恢复并禁止下一次启动，不抢回用户终端。

## 固定批准对象与信号

启动不再重新按原 CLI/目录路径 exec/chdir：原生适配器持有批准对象，复制批准源 FD、核对摘要并保留安全元数据，再由 posix_spawn 的 fchdir 文件动作选择目录对象。仅支持受限原生 Mach-O 入口；复制不会冻结所有运行时依赖，同 UID 恶意改写私有副本不在完整防御保证内，确认卡须披露自更新/相对资源兼容风险。过期/取消/替换计划会关闭未消费对象；确认后复核不执行第二次 --version。

程序根 PID 信号与唯一 Wait4(WNOHANG) 回收在同锁内串行；回收后或所有权不明时不再 signal。父进程 SIGCHLD 自动回收策略不安全时禁用程序停止。用户在终端按 Ctrl-C 则是前台组广播，不能保证只影响该根进程；产品不以此扩大程序信号范围。

取消响应丢失时弹窗仍提供状态查询与结束服务，保持执行禁用；查询不重新批准。参考清单过期即不执行，哪怕前面的启动已完成，亦不延期；按真实尝试计数和执行状态解释局部结果。

清理不得递归追随可变路径。当前实现持有父/目录/入口 FD，对命名对象原子捕获后核身份，仅删除自有单层文件与空目录；身份异常或错误对象还原受阻保持恢复状态。随机私有槽不是同 UID 权限隔离，公开 API 无法保证任意同 UID 最后一刻置换零误删。普通路径置换的实测与这一边界必须分开说明。

安全构建的保证以可信 zsh 解释器、模块和词法解析为前提；特殊表/分派不可信时条件分支失败，不调用可覆盖命令。攻击性词法 alias、trap、PS4 以及任意同 UID 篡改不属于可由 source 文件建立的隔离。活动到期清除尚未消费的 bootstrap 并拒绝新 session；保留既有 session 只用于受限清理，不创建新登录通道。
