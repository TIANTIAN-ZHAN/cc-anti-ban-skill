# 验证专题：批准对象与进程监督

这是已有隔离验收主题的公开摘要，不是用户真实 Claude/账号/网络验收记录。原始个人机器路径、内部会话标识和外部工作目录不属于公开复现依赖。

覆盖持有源/目录 FD、原路径/目录置换、原位变更拒绝、唯一 Wait4 与根 PID signal 同锁、raw/中断/前台丢失及短命进程。

用户 Ctrl-C 为前台组广播，程序停止只对仍拥有根 PID；不承诺清空后代或撤销副作用。

复现从 [统一验证说明](validation.md)开始，使用 [对应源码测试](../internal/runner/process_darwin_test.go)。当前代码与测试是事实来源；不要把历史测试结果用于推定未测试的平台、真实账户或服务可用性。
