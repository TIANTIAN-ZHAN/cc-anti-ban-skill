# 验证专题：可变名称与活动生命周期

这是已有隔离验收主题的公开摘要，不是用户真实 Claude/账号/网络验收记录。原始个人机器路径、内部会话标识和外部工作目录不属于公开复现依赖。

覆盖目录/叶名置换、捕获错误对象的无覆盖还原、还原受阻保持 undo；取消后的迟到 CONNECT 成功不能启动后续 TLS/HEAD。

清理不递归追删；随机私有槽不是同 UID 隔离，公开接口没有按 expected inode 原子删除的保证。

复现从 [统一验证说明](validation.md)开始，使用 [对应源码测试](../internal/runner/artifact_test.go)。当前代码与测试是事实来源；不要把历史测试结果用于推定未测试的平台、真实账户或服务可用性。
